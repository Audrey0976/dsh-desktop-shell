# Security policy

## Supported versions

Only the newest DSH Desktop Shell release is supported during the preview.
The shell may deliberately block a newer dsh compatibility line until a shell
release has validated it.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving credential exposure,
arbitrary navigation, update integrity, installer privilege, or process
ownership. Use the repository's private GitHub Security Advisory reporting
form. Include a minimal reproduction without real API keys or conversations.

The project aims to acknowledge a complete report within seven days. There is
no bug bounty or guaranteed remediation timeline.

## Scope boundaries

Reports caused solely by upstream DeepSeek Harness should also be reported to
its maintainers. This project does not silently replace the shell executable;
the first preview is unsigned and links users to GitHub Releases for shell
updates.
