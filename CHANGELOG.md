# Changelog

## [0.1.0] - 2026-08-14

- First public Windows x64 preview.
- Native WebView2 desktop chrome, title-bar menus, tray lifecycle, adaptive
  startup animation, and resilient `Ctrl+B` sidebar shortcut.
- Cross-platform Node bootstrap with JSON Lines control protocol.
- Random loopback origin, compatible dsh update prompts, atomic activation,
  health checks, rollback, and failed-version quarantine.
- Per-user Inno Setup installer and portable ZIP release pipelines.
