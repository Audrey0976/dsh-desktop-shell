# Visual asset provenance

`whale.svg` is copied from the MIT-licensed DeepSeek Harness favicon and is
used to build the derivative application icon and the metal-outline startup
animation. The upstream copyright notice is retained in
`THIRD_PARTY_NOTICES.txt`.

The square application icon is a community derivative. The startup surface
extracts only the whale silhouette, renders it as a recessed metal outline,
and applies a moving specular highlight. Neither asset indicates official
DeepSeek endorsement.
