## DSH Desktop Shell v0.1.0 (unsigned preview)

First public Windows 10/11 x64 preview of the unofficial community desktop
shell for DeepSeek Harness.

Highlights:

- Native WebView2 application window, integrated title/menu bar, adaptive
  metal whale startup animation, and close-to-tray lifecycle.
- Bundled Node 24 and verified `@deepseek-ai/dsh@0.1.0-rc.6`; no separate Node
  installation is required.
- Random loopback port, exact-origin WebView restriction, compatible dsh
  update prompts, atomic activation, health check, and automatic rollback.
- Setup and Portable packages with SHA-256 checksums, SPDX SBOM, and notices.

This preview is not code-signed. Windows SmartScreen can show an unknown
publisher warning. Download only from this GitHub release and verify the file
against `SHA256SUMS.txt`.

The project is unofficial and is not affiliated with or endorsed by DeepSeek.
