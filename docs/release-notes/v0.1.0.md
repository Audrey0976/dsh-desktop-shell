## DSH Desktop Shell v0.1.0（未签名预览版）

这是非官方社区项目 DSH Desktop Shell 的首个 Windows 10/11 x64 公开预览版。

- 原生 WebView2 应用窗口、标题栏内菜单、适配明暗主题的金属鲸鱼启动动画，以及关闭后驻留托盘。
- 内置 Node 24 和已验证的 `@deepseek-ai/dsh@0.1.0-rc.6`，无需另行安装 Node。
- 随机回环端口、精确 origin 导航限制、兼容 dsh 更新提示、原子切换、健康检查与自动回滚。
- 同时提供安装版和便携版，并附带 SHA-256、SPDX SBOM 与第三方声明。

本预览版没有代码签名，Windows SmartScreen 可能提示未知发布者。请只从本 GitHub Release 下载，并用 `SHA256SUMS.txt` 校验文件。便携版的 `data\` 目录可能包含 API Key，请妥善保管。

本项目与 DeepSeek 无隶属关系，也未获得其官方背书。

## DSH Desktop Shell v0.1.0 (unsigned preview)

First public Windows 10/11 x64 preview of the unofficial community desktop shell for DeepSeek Harness.

- Native WebView2 application window, integrated title/menu bar, adaptive metal whale startup animation, and close-to-tray lifecycle.
- Bundled Node 24 and verified `@deepseek-ai/dsh@0.1.0-rc.6`; no separate Node installation is required.
- Random loopback port, exact-origin WebView restriction, compatible dsh update prompts, atomic activation, health check, and automatic rollback.
- Setup and Portable packages with SHA-256 checksums, SPDX SBOM, and third-party notices.

This preview is not code-signed. Windows SmartScreen can show an unknown publisher warning. Download only from this GitHub release and verify the file against `SHA256SUMS.txt`. The Portable edition's `data\` directory can contain API keys and must be protected accordingly.

This project is unofficial and is not affiliated with or endorsed by DeepSeek.
